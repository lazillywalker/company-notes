# Company Notes — 会社の教育ノート

ローカルOllamaを使った教材管理・応答検証・複数モデル比較の実験ツールです。モデルの重みを学習し直すものではなく、承認した教材を検索し、質問と一緒にモデルへ渡します。Python標準ライブラリのみで動作します。

A local-first experimental tool for curated company notes, reference-grounded answers, and comparison of local Ollama models. No fine-tuning; approved notes are retrieved and supplied as context. Uses only the Python standard library.

**[配布用ZIPをダウンロード（v0.2.0）](https://github.com/lazillywalker/company-notes/releases/download/v0.2.0/company-notes.zip)**

ZIPを展開して、そのフォルダーで `python3 launch.py` を実行してください。モデル選択・3モデル比較を含む研究用版です。Python 3.10以上が必要です。AI機能にはローカルOllamaと導入済みモデルを使用します。

Download the ZIP above, extract it, and run `python3 launch.py` in the extracted folder. Python 3.10+ is required; AI features use your local Ollama and installed models.

## 必要な環境

- Python 3.10以上（Python 3.12 / Linux Mintで開発）
- Webブラウザー
- AI機能を使う場合：ローカルOllama（127.0.0.1:11434）と導入済みモデル

## 起動

このフォルダーで次を実行します。

```sh
python3 launch.py
```

ブラウザー: http://127.0.0.1:8766
モデル指定: `python3 gui.py --model qwen3:4b --open-browser`
AIチャットにはローカルOllamaとインストール済みモデルが必要です。教材の手動登録・閲覧・バックアップにはAIは不要です。外部へのモデルダウンロードは行いません。

モデル設定の候補はOllamaの `/api/tags` から取得します。「モデル一覧を更新」で追加・削除を反映できます。TinySwallow (`hf.co/SakanaAI/TinySwallow-1.5B-Instruct-GGUF:Q5_K_M`) もインストール済みなら教育・応答チャットで選択できます。接続失敗時は既定候補と案内を表示し、生成時には従来どおりローカルモデルを確認します。3モデル比較の組み合わせは従来どおりです。変更時にアプリが起動中だった場合は、その端末で Ctrl+C を押してから `python3 launch.py` で起動し直してください。

## 操作

1. 教育チャットで情報を相談します。AIの提案は未登録です。
2. 教材編集欄へ内容を転記し、分類・対象・日英本文・出典・期間・公開範囲を指定します。
3. 変更前後を確認して保存します。承認済みの最新の版だけが回答の検索対象です。下書き保存や取下げは以前の承認版も検索対象から外します。
4. 応答チャットで質問し、参照元を確認します。間違いは教育側へ送れます。
5. 訂正記録は経緯用です。正式情報は元の教材を編集して承認してください。
6. 履歴から以前の版を編集欄へ戻し、新しい版として承認できます。

日本語とEnglishの切替は画面の主要操作と回答言語に反映されます。編集欄は日英併記です。検索用語は両言語で登録すると検索しやすくなります。

## 保存・バックアップ

notes.sqlite3が正本です。「6ファイル出力・バックアップ」でexports以下に5分類のJSON、案内JSON、DBの完全バックアップを保存します。復元時はアプリを停止し、現在のnotes.sqlite3を別名で保管してから、backup.sqlite3をnotes.sqlite3としてコピーします。チャット履歴もDBバックアップに含みます。会話は現状無期限保存です。

## 現段階の制約

担当者が自分のPCで使う初期版です。教育・応答画面は分離していますが、本人認証や役割別のアクセス制御はありません。承認者名は記録用で、本人認証ではありません。顧客への直接公開用ではありません。

有効日は日本時間・終了日を含みます。価格、税、店舗条件は本文と対象欄へ記載します。数値専用欄、競合情報の自動検出、価格の確定計算は未実装です。

検索は日英本文・用語の文字列照合です。意味検索や検索の自動再試行は未実装です。最大6項目を渡します。日英の翻訳文は手動確認が必要で、自動同期はありません。質問ごとに独立検索します。AIの誤答を完全には防げないため、参照元を確認してください。

旧形式の教材データの自動移行は未実装です。会話ログの追加カラムは起動時に補完します。

## 検証

`python3 -m unittest -v test_notes.py`

日英検索、期限切れ、下書きへの更新、社内情報の除外、逆転した日付、訂正記録の除外などを確認します。実機でのモデル回答とブラウザー表示は別途確認が必要です。

## JSON入力と週間営業時間

教育画面の「JSON入力・ファイル読込」から、JSONを貼付またはファイル選択して「編集欄へ読み込む」を押します。教材1件ずつ対応します。営業時間の例ボタンで形式を確認できます。読み込みだけでは保存せず、新規の下書きとして編集・確認後に保存します。既存の教材更新には一覧の「編集」を使ってください。

通常の教材形式は category（0〜4）、title、ja または en、visibility（public/internal）。その他の欄は任意です。

週間営業時間は会社分類（0）で対象店舗 scope を必須とします。weekly_hours に mon/tue/wed/thu/fri/sat/sun の7日を指定し、各日を {"status":"open","periods":[["09:00","18:00"]]} の形式にします。closed は休業、unknown は未確認で、いずれも periods は空配列です。昼休みなどは複数時間帯で登録できます。時刻は日本時間、日付をまたぐ営業は曜日ごとに分割します。祝日・臨時営業は通常週間予定からは推測しません。

## 応答ログ

応答が正常に完了したとき、質問・回答・参照教材の本文と版・UTC日時を自動保存します。応答画面の「ログを表示・更新」で最新50件から閲覧でき、「さらに古い50件」で過去へ進めます。画面の日時はブラウザーの現地時間です。「全ログをJSON出力」で exports に全件を書き出します。アプリを再起動してもDBの記録は残ります。生成失敗や送信前の文章は記録しません。

## 3モデル比較

起動後、http://127.0.0.1:8766/compare を開きます。比較対象は `lfm2.5:8b`、`qwen3:8b`、`qwen3.5:9b` の3モデルです。事前にローカルへ導入してください。対象を変える場合は `comparison.py` の `MODELS` を編集します。比較時は条件を揃えるため、Ollamaに常駐しているモデルをアンロードします。ほかのOllama作業がない状態で実行してください。回答や処理時間の比較結果は実験記録であり、汎用的な性能順位を示すものではありません。

## テスト一式

```sh
python3 -m unittest discover -v
```

テストではモデル呼び出しをモックします。実際のモデルの応答品質とブラウザー表示は別途確認が必要です。

## データの扱い

初回実行時に空の `notes.sqlite3` を作成します。開発者の教材・会話履歴・出力データは配布しません。DB、`exports/`、`data/`、`reports/` はGit管理から除外しています。

## Linuxの起動ショートカット

必要なら、以下のコマンドで現在の配置先を使ったショートカットを作成できます。

```sh
python3 setup.py
```

生成された 「会社の教育ノート.desktop」 をダブルクリックし、Linux Mintで確認が出た場合は「起動を許可」を選択します。フォルダーを移動したら作り直してください。終了は起動した端末でCtrl+Cです。

## サンプル教材

`samples/` に架空のサンプル教材と確認用質問があります。JSONを1件ずつ読み込み、確認して承認してください。サンプルの売出し期間は2026年11月7〜15日です。期間外は日付欄と本文を合わせて変更してください。
