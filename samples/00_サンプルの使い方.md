# サンプル教材の使い方

すべて架空の会社・商品・訂正事例です。日本語と英語を収録しています。

1. 教育画面の緑色の「JSONから教材を読み込む」を開く。
2. 「ファイルを選択」で01_company.jsonを選ぶ。
3. 「編集欄へ読み込む」を押す。
4. 内容を確認し、状態を「承認」に変更する。
5. 「変更内容を確認」→「この内容を保存・登録」。
6. 02〜05も1件ずつ同じ手順で登録する。

| ファイル | 内容 |
|---|---|
|01_company.json|会社案内、曜日別の営業時間|
|02_policy.json|基本方針、用語|
|03_products.json|商品、価格、期間限定の売出し|
|04_procedures.json|返品・交換の受付手順|
|05_corrections.json|日曜日の閉店時刻を間違えた訂正記録|

商品サンプルの期間は2026年11月7〜15日です。期間外は回答に使われません。現在の日付で実験する場合はstart・endと、日本語・英語本文内の期間を一致させて変更してください。日付欄だけを変更すると本文と矛盾します。通常価格を期間外にも案内する場合は別の通常商品教材を作成してください。

訂正記録は社内用で、承認しても回答検索には使われません。元の教材の編集と承認は別に行います。

下書きのままでは回答に使われません。初期状態ではサンプルは自動登録されていません。

English: Import each JSON file individually through Teach & manage → Import notes from JSON → Choose file → Load into editor. Select Approved, preview, then save. The promotion is valid only November 7–15, 2026. For another experiment period, update both date fields AND dates in both language texts. Correction records are audit-only and are excluded from answer retrieval.
